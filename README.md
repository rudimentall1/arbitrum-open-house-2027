# Arbitrum Open House 2027 — Buildathon Lab

A working repository for buildathon preparation, evidence-based idea selection, and implementation.

## Start here

1. Read `AGENTS.md`.
2. Read `PROJECT_CONTEXT.md`.
3. Read `DECISIONS.md` and `RESEARCH_LOG.md` before proposing or researching another idea.
4. Check `TASKS.md` for the current next step.

## Requirements

- Node.js 20 or newer (uses the built-in test runner).

## Setup

```bash
npm test
npm run check
```

No third-party dependencies are required.

## Working agreement

Keep research evidence, decisions, task status, and project context current. Do not repeat closed research or turn unverified assumptions into facts. Commit documentation changes with the corresponding code changes.
